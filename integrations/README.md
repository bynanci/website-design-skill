# Integrations

The core skill must remain platform-agnostic.

Optional adapters may document how to use the methodology with specific ecosystems, but they must not become dependencies of `SKILL.md`.

Potential adapter categories:

- AI reasoning/coding agents
- design and prototyping environments
- source control providers
- browser/research tools
- frontend frameworks
- CMS platforms

Rules:

1. Core workflow terminology stays capability-based.
2. Adapters may translate capabilities into platform-specific operations.
3. Core artifacts must remain portable between adapters.
4. A platform integration must not redefine the methodology.
