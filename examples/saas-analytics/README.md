# Synthetic SaaS Redesign Example

This example demonstrates how the skill turns a small, structurally inconsistent website into explicit redesign artifacts.

The example is synthetic and intentionally simple. Its purpose is to show the decision chain rather than visual polish.

## Flow

```text
input/current-sitemap.md
→ output/navigation-comparison.md
→ output/homepage-spec.md
```

## What to inspect

1. The input mixes industry, audience, and lifecycle concepts under one `Solutions` group.
2. The navigation artifact identifies the taxonomy problem before proposing a new hierarchy.
3. The page specification preserves required source content.
4. Component actions use the governance order:
   `Reuse → Extend → Variant → Compose → New`.

This example should remain implementable without assuming a specific AI model, design tool, or frontend framework.
