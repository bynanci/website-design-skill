## Gate before token or component implementation

- [ ] The same required content and section order were evaluated for all options.
- [ ] Content coverage is unchanged or an explicit upstream change request exists.
- [ ] Preference, observation and assumptions are labeled separately.
- [ ] Mobile / zoom and keyboard implications are specified rather than imagined.
- [ ] Any new pattern has a reuse justification.
- [ ] No direction is called "accessible", "fast", or "award-winning" without evidence.
- [ ] A chosen direction is recorded with its trade-offs.
