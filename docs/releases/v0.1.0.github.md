# Website Design Skill v0.1.0

## English

The v0.1 core provides a portable website-redesign workflow and explicit artifact contracts for discovery, information architecture, wireframes, visual direction, design systems, implementation planning and validation.

Benchmark suite `0.1.0` remains pinned to core commit `7d64090710ef20f1d24cea6b46199391d3c09c18`. Two independent ChatGPT web executions, using the visible model labels GPT-6 and GPT-5.6 Sol, each score **40/40** across IA audit, component reuse and the synthetic B2B end-to-end case. Each case used a fresh Temporary, Unpersonalized conversation and one unchanged pinned packet. Complete original outputs, packet hashes, isolation disclosures and independent criterion-level reviews are retained. No API key was needed.

The repository's hard evidence gate passes with two official runs, two distinct agent signatures and no failures or warnings. The release request verifies its exact candidate's validation, browser smoke and canonical Vercel status before creating the tag and release. Later adapters and implementation fixtures retain separate evidence and are not covered by the frozen core scores.

The two visible model labels belong to one product/provider. They do not establish cross-vendor compatibility or disclose hidden backend revisions. Scores measure twenty planning-artifact criteria; they do not certify production UX, real user-study results or rendered accessibility compliance. Archived UI evidence and attributed controller observations support eligibility but are not exhaustive provider-internal activity logs.

## 繁體中文

v0.1 核心提供可攜的網站改版流程與明確交付契約，涵蓋需求探索、資訊架構、線框稿、視覺方向、設計系統、實作規劃與驗收。

評估套件 `0.1.0` 維持凍結於核心 commit `7d64090710ef20f1d24cea6b46199391d3c09c18`。兩次獨立 ChatGPT web 執行，所選模型標籤分別為 GPT-6 與 GPT-5.6 Sol，在資訊架構稽核、元件重用及合成 B2B 端到端案例中均取得 **40/40**。每個案例使用全新的 Temporary、Unpersonalized 對話與一份未變更的指定資料包。完整原始輸出、雜湊、隔離限制及獨立逐項評分均已保存，過程未使用 API key。

Repository 的正式證據檢查通過：兩次官方執行、兩個不同 agent signature，沒有 failure 或 warning。發布請求會先核對確切候選提交的程式驗證、瀏覽器 smoke 與正式 Vercel 狀態，再建立 tag 與 Release。後續 adapter 與實作試作維持獨立證據，未納入本次凍結核心的分數。

這兩個模型標籤來自同一產品與供應商，不能推論跨供應商相容性或未公開的後端版本。分數衡量二十項規劃交付標準，不代表正式產品 UX 成效、真人研究結果或畫面可及性合規。保存的 UI 紀錄與具名控制者觀察支持執行資格，但不構成完整的供應商內部活動稽核。
