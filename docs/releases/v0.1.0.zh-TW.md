證據快照日期：2026-11-17。本文件備妥 v0.1.0 發布證據。發布須依下列檢查清單辦理；正式紀錄以 [Issue #1](https://github.com/bynanci/website-design-skill/issues/1) 與 [GitHub Releases](https://github.com/bynanci/website-design-skill/releases) 為準。

## 核心基線

v0.1 核心定義跨平台網站改版流程、可重用交付契約、聚焦的行為評估，以及合成的端到端 B2B 案例。流程涵蓋探索、資訊架構、線框、視覺方向、設計系統、實作規劃與驗收。

Benchmark 證據使用 suite `0.1.0` 與凍結核心 commit `7d64090710ef20f1d24cea6b46199391d3c09c18`。核心 pin、標準案例及評分準則均未變更。Main 後續的選用 adapter、實作 fixture 與測試各有其證據；本次執行未評估這些新增內容。

每個案例均使用全新的 Temporary、Unpersonalized ChatGPT web 對話，並只提供一個未修改的指定 ZIP 資料包。執行未使用 API key。生成輸入不含評估者參考資料及評分準則。原始 Markdown 下載、隔離紀錄與執行資訊均已保存。不同評估者在生成結束後評分凍結輸出；兩次執行均為 `manual_edit=false`。

這些是依 repository 人工 runner 協定完成的正式 UI 執行。其身分紀錄、輸入隔離、原始輸出保存、獨立逐項審查與 repository 驗證，使其有別於一般人工操作測試。詳見[相容性矩陣](../../benchmarks/compatibility-matrix.md)。

## 限制

兩個 signature 是同一供應商、同一產品上的所選模型標籤。它們不能證明跨供應商或所有平台相容，也未揭露隱藏的後端版本。資格審查依據保存的 UI 證據及註明來源的現場操作者觀察；可見活動摘要不是完整的供應商內部稽核紀錄。

分數衡量三個合成案例中的二十項凍結規劃交付準則。它們不代表正式產品的使用成效、實際真人／使用者研究、渲染後可及性合規或部署成功。核心契約或 benchmark 變更需另行決定版本並取得乾淨證據。[Roadmap](../../ROADMAP.zh-TW.md) 保留更廣情境與 adapter 工作的獨立規劃。
