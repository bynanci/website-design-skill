## Core baseline

The v0.1 core defines a platform-agnostic website-redesign workflow, reusable artifact contracts, focused behavioral evaluations and a synthetic end-to-end B2B fixture. The workflow covers discovery, information architecture, wireframes, visual direction, design systems, implementation planning and validation.

The benchmark evidence uses suite `0.1.0` at exact frozen core commit `7d64090710ef20f1d24cea6b46199391d3c09c18`. The core pin, canonical cases and rubric are unchanged. Later optional adapters, implementation fixtures and tests on main have their own evidence; these runs do not evaluate those additions.

## Limits

The two signatures are selected model labels on one product from one provider. They do not establish cross-vendor or all-platform compatibility, and hidden backend revisions are not disclosed. Eligibility relies on archived UI evidence plus attributed live operator observations; visible activity summaries are not a complete provider-internal audit.

The scores measure twenty frozen planning-artifact criteria across three synthetic cases. They do not establish production UX efficacy, actual human/user-study results, rendered accessibility conformance or production deployment success. New core-contract or benchmark changes require their own version decision and clean evidence. The [roadmap](../../ROADMAP.md) retains broader coverage and adapter work separately.
