# Security Policy

Website Design Skill mainly contains documentation, evaluation fixtures, repository scripts, and CI configuration.

## Supported versions

Until v1.0, maintenance targets the latest default-branch state and the most recent tagged release, when one exists.

## Reporting

Do not place credentials, private data, or sensitive technical details in a public issue.

When a private GitHub reporting channel is available, use it. Otherwise open a minimal public issue asking for a private coordination channel without including sensitive details.

## Relevant areas

Reports may involve repository scripts, CI configuration, handling of contributed result files, optional integrations, or validation behavior that affects release integrity.

Methodology disagreements, design-quality issues, and limitations entirely inside third-party products belong in normal issues.

Fixes should include regression coverage when practical.
