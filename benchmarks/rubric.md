# Cross-Agent Benchmark Rubric

Score each criterion from 0 to 2.

## Scale

### 0 — Fail

The behavior is absent, incorrect, or contradicts the skill contract.

### 1 — Partial

The behavior is present but incomplete, weakly justified, or ambiguous.

### 2 — Pass

The behavior is explicit, correct, and consistent with the skill contract.

---

# Case A — IA Audit

Maximum: 12

## A1. Correct workflow layer

The agent treats the task as information architecture and does not jump directly to visual design or implementation.

## A2. Mixed taxonomy detection

The agent identifies that Healthcare, Enterprise, and Getting Started represent incompatible grouping models.

## A3. User-impact explanation

The agent explains why the taxonomy harms predictability, findability, or comprehension.

## A4. Content integrity

All required source content receives an explicit destination or disposition.

## A5. Evidence discipline

Unsupported analytics, user research, or competitor evidence is not invented. New labels are marked as hypotheses when necessary.

## A6. Grouping rationale

The proposed structure states the dominant organizing logic behind major groups.

---

# Case B — Component Reuse

Maximum: 12

## B1. Inventory-first behavior

The agent inspects/maps the supplied component inventory before proposing new components.

## B2. Existing component reuse

Hero, logo proof, capabilities, metrics, case study, and CTA reuse existing responsibilities.

## B3. New-component restraint

The plan comparison is recognized as the primary legitimate structural gap.

## B4. No page-specific duplicates

The agent avoids unnecessary Enterprise-specific duplicates of existing components.

## B5. Action rationale

Sections receive explicit Reuse / Extend / Variant / Compose / New decisions with rationale.

## B6. System implications

The agent considers responsive/accessibility implications for the comparison pattern and does not invent token changes without evidence.

---

# Case C — End-to-End

Maximum: 16

## C1. Evidence integrity

Missing analytics/research are kept as unknowns rather than fabricated.

## C2. Audit before redesign

Structural findings precede page styling decisions.

## C3. IA consistency

The proposed information architecture resolves the known mixed-taxonomy problem.

## C4. Content coverage

Every required content item is accounted for.

## C5. Page hierarchy

The homepage has a coherent evaluator journey and explicit CTA hierarchy.

## C6. Component governance

The page maps to the existing component inventory before new components are proposed.

## C7. Implementation discipline

Implementation respects the existing stack and separates structure from visual polish.

## C8. Validation discipline

Responsive, accessibility, evidence, content, and component checks are explicit.

---

# Aggregate

Maximum total: 40

Recommended interpretation:

- 36–40: strong compatibility
- 30–35: usable with minor contract ambiguity
- 20–29: material interpretation drift
- 0–19: incompatible or benchmark execution failure

The aggregate is diagnostic. Always review criterion-level failures before changing the skill.
